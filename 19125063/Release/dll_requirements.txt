FeatureMatcher.exe - runtime requirements (Windows x64)
========================================================

Required DLL (put it in the same folder as FeatureMatcher.exe, or on PATH):
  opencv_world4xxx.dll
      Found in <OpenCV>\build\x64\vc16\bin\  (e.g. opencv_world4100.dll for OpenCV 4.10.0).
      Use exactly the version the exe was built against.

Optional DLL:
  opencv_videoio_ffmpeg4xxx_64.dll
      Only needed to read video files. Not needed for images or the camera.

Microsoft Visual C++ Redistributable 2015-2022 (x64):
  VCRUNTIME140.dll, VCRUNTIME140_1.dll, MSVCP140.dll
      Installed on most PCs; otherwise install vc_redist.x64.exe from
      https://aka.ms/vs/17/release/vc_redist.x64.exe

Check the exact list with (Developer Command Prompt):
  dumpbin /dependents FeatureMatcher.exe
